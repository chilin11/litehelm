# LiteHelm protocol v1

Base URL: user-supplied HTTPS origin; a user-managed HTTPS reverse proxy forwards to `127.0.0.1:9091`. Every endpoint requires `Authorization: Bearer <token>`. No cookies, browser CORS, or arbitrary command execution. Requests/responses are JSON. Errors use non-2xx status and `{ "error": "message" }`. Mutations MUST NOT be automatically retried. Timestamps are Unix seconds. Byte counts use bytes.

- `GET /api/v1/system`: `{ "hostname":"node", "os":"Debian GNU/Linux 12", "arch":"arm64", "uptime_seconds":123, "cpu_percent":12.5, "cpu_cores":2, "load":[0.2,0.3,0.1], "memory":{"total":1000,"used":400,"available":600}, "swap":{"total":0,"used":0}, "disk":{"total":1000,"used":400,"free":600}, "network":{"rx_bytes":123,"tx_bytes":456}, "timestamp":123, "capabilities":{"process_signal":true,"service_control":true,"power":false} }`. CPU is measured across approximately 150 ms per request. Network counters are cumulative non-loopback totals. Client derives rates from consecutive valid samples, clearing the baseline on page changes/background/connection changes/counter reset.
- `GET /api/v1/processes?limit=100&sort=cpu`: `{ "processes":[{"pid":123,"name":"nginx","user":"root","state":"S","cpu_percent":1.2,"memory_bytes":1234,"start_time":"123456"}], "timestamp":123 }`. Default sort is memory; optional cpu sort is lifetime average. Limit maximum 300. Do not show argv/environment. `start_time` is an opaque Linux start-ticks string.
- `POST /api/v1/processes/{pid}/signal`: `{ "signal":"TERM", "start_time":"123456" }`. TERM/KILL only. pidfd + start-time check prevents PID reuse; requires Linux 5.3+. Protects PID 1, own/ancestor processes and critical process prefixes. Success `{ "ok":true,"message":"Signal sent" }` means delivery accepted, not guaranteed termination.
- `GET /api/v1/services`: `{ "services":[{"name":"nginx.service","description":"Web server","load_state":"loaded","active_state":"active","sub_state":"running"}], "supported":true }`. Merges loaded and installed units; uninstantiated templates omitted. Installed but unloaded units show `not-loaded/inactive/dead`; masked units `masked/unknown/masked`. Non-systemd hosts return an empty array and supported=false. Oversized output returns an error instead of silent truncation.
- `POST /api/v1/services/{name}/action`: `{ "action":"start" }`. start/stop/restart only; URL-encoded unit names restricted to `[a-zA-Z0-9_][a-zA-Z0-9_.@:-]*.service`. Critical system services protected. `{ "ok":true,"message":"Service action completed" }`; refresh list after acceptance.
- `GET /api/v1/services/{name}/logs`: `{ "logs":"...", "truncated":false }`. Last 80 lines, capped at 64 KiB with valid UTF-8. No continuous streaming.
- `POST /api/v1/power`: `{ "action":"reboot", "confirm":"<hostname>" }`. reboot/poweroff only, requires root/systemd and `-allow-power`; exact hostname confirmation required. Schedules action after 5 seconds; `{ "ok":true,"message":"Power action scheduled in 5 seconds" }`.

Client: dashboard visible + foreground polling every 5 seconds; single serialized request, no background sampling, database or analytics. Other pages on-demand. HTTPS required except explicit debug-loopback use. Standard TLS validation, no redirects to external login pages, 10-second connect / 20-second read timeouts, bounded JSON responses. Credentials encrypted locally using Android Keystore and excluded from backups. A new connection replaces the previous saved configuration only after validation completes on the active page.
